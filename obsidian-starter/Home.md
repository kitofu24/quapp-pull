## Working with Codex

Open this vault as a local Codex project. Make the vault the primary folder so Codex discovers AGENTS.md automatically.

Example requests:

- Read my Quapp notes and help me choose the next task.
- Organize my inbox and link related notes.
- Save today's confirmed decisions and next actions in my Quapp note.

The notes preserve knowledge between chats. Ask Codex to read relevant notes when starting work and save useful outcomes when finishing.
